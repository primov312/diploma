## Browser scenario (8.2)

`e2e/smoke.spec.ts` runs the full user story on the real stack: register → seller-filtered history → marketplace
search → *Apply for credit* → choose payments → saved decision (reload and list) → custom amount with AI →
sign out → private page redirects to login. A second test signs in as Riley with the demo-account button, runs the
visit analysis, checks the Budapest map (district XIII most visited, district VIII selectable) and gets a REVIEW
decision with plain-language reasons. Approval, rejection and review are also covered at API level in
`ApplicationFlowTest` and reproduced for every persona in [DEMO_SCENARIOS.md](DEMO_SCENARIOS.md).

Screenshots in [`docs/screenshots/`](screenshots/) were regenerated by `SCREENSHOTS=1 npx playwright test smoke`.

## Not verified

- **A successful live Gemini answer.** On 2026-10-22 a key was added to `diploma/.env` and checked live:
  - the key authenticates (the model list returned 46 models with `generateContent`, including `gemini-3.8-flash`);
  - every generation call returned **HTTP 402 `RESOURCE_EXHAUSTED` — “Your prepayment credits are depleted”** for the
    key's Google AI Studio project, on all six models tried; `gemini-2.5-flash` returned 404 (no longer offered to new users);
  - the live test `pytest tests/test_gemini.py -k live` therefore failed at its first assertion, and in doing so
    verified the real fallback path: the report came back `AI_UNAVAILABLE` with the deterministic metrics, and the
    service logged only `gemini call failed` with the HTTP status.

  As an alternative provider, AI mode can now call Anthropic's Claude Haiku 5.5 (`AI_PROVIDER=ANTHROPIC`). Its adapter
  is covered by `tests/test_anthropic.py` with the SDK client faked (structured-output request, image block, refusal and
  missing-key fallback, rejected figures); its live test is skipped until an `ANTHROPIC_API_KEY` is configured — no
  Anthropic credentials existed on this machine on 2026-10-23. A value was added on 2026-10-23 as `ANTROPICS_API_KEY`,
  but Anthropic rejected it with HTTP 401.

  Jev (TypeSafe, `AI_PROVIDER=JEV`, now the default) was added on 2026-10-23. Its adapters are covered by
  `tests/test_jev.py`; the live test is skipped until `TYPESAFE_API_KEY` is set.

  After adding credits to the project, re-run the live test from [DIPLOMA_RUNTIME.md](../rocket-credit-deployment/DIPLOMA_RUNTIME.md#turning-on-gemini-ai-mode-and-testing-it). The default model was changed to `gemini-3.8-flash`.
- **A real Facebook login round trip.** It needs the developer's own Facebook account. The Meta app credentials were
  checked (Graph issues an app token), and the OAuth flow is covered with Graph mocked.
